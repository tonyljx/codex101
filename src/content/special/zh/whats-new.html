2026 年 7 月 27–31 日

以更低费率使用 GPT-5.6 Terra 和 Luna

GPT-5.6 Terra 的费用现已降低 20%，GPT-5.6 Luna 则降低 80%；输入、缓存输入和输出费率都按相同比例下调。更新后的用量限制与费率让 Terra 更适合日常工作，也让 Luna 尤其适合聚焦的编码任务和高吞吐工作。

从浏览器和已打开标签页查找有用上下文

在 ChatGPT 桌面 App 中，内置浏览器可以从浏览历史中查找页面，也可以直接从地址栏搜索 Google。当任务需要先前的上下文时，ChatGPT 还可以请求搜索你的浏览历史。

Chrome extension 允许你提及已打开的标签页，把页面中选中的文本带入 side chat，询问 YouTube 视频内容，或从页面右键菜单选择 Ask ChatGPT。ChatGPT 把浏览历史纳入任务前，请先评审并批准相关请求。

跨多个仓库评审改动

当本地项目包含多个文件夹时，桌面 App 会显示每个仓库及其中修改的行。选择 Review（评审），即可集中检查这些 diff，无需在多个独立评审视图之间切换。

提示词：

Review the changes across every repository in this project, identify integration risks, and summarize the fixes needed before I open a pull request.

在聊天中继续完善生成的图片

在扩展查看器中打开生成的图片，然后在 Focused view（聚焦视图） 与 Canvas view（画布视图） 之间切换。你可以为多张图片添加评论，选择想保留的版本，并直接在聊天中要求有针对性的修改。详情见图像生成。

找到需要关注的聊天

桌面 App 新增的 Activity view（活动视图） 会集中显示最近参与过的聊天和需要关注的工作。选择侧边栏中的铃铛即可打开。

阅读 7 月 30 日桌面端发布说明。

合作伙伴只会在相关信息可用时收到你的姓名、电子邮件地址和头像。每个 plugin 请求的访问权限仍需单独评审和批准。详情见7 月 29 日登录功能公告。

比较安全扫描并管理发现

托管 Codex Security plugin 的 0.1.14 和 0.1.15 版本新增扫描比较、误报反馈、限定范围的 SECURITY.md 策略，以及更清晰的仓库与发现历史。你可以选择要在 Linear 或 GitHub Issues 中跟踪的发现；批准前，Codex 会先评审拟执行的操作。

从终端、CI 或 TypeScript 运行安全扫描

公开的 @openai/codex-security CLI 和 TypeScript SDK 已升级至 0.1.5，其版本号与 Codex Security plugin 相互独立。你可以使用该软件包从 CLI 运行扫描，在 CI 中评审 pull request 改动并上传 SARIF 结果，或对 GitHub 仓库或固定 CSV 清单运行可恢复的批量扫描。

Codex Security TypeScript SDK 还允许你在自己的工具中集成扫描、进度报告、成本控制和取消操作。软件包本身是公开的，但运行扫描仍需要 Codex Security 访问权限。部分完整仓库扫描还要求 Trusted Access for Cyber。

组织 session 并扩展 Codex CLI 0.146.0

Codex CLI 0.146.0 允许使用 /new release prep 或 /clear bug bash 为新聊天命名、置顶重要 thread，并在不关闭 side conversation 的情况下切换。它还新增临时聊天 fork、面向兼容自定义模型提供商的独立 Web 搜索、由 executor 提供的 skills，以及 Agent Plugins manifests、工作区 plugin 发布和其他 plugin marketplaces 支持。

对于自定义客户端，app server 现在可以筛选已置顶 thread、创建内存内 fork、检查已安装连接器状态并读取连接器 metadata。实验性 WebSocket 支持还可以让 app-server 连接远程 Code Mode host。开放远程连接前，请先检查 app-server 安全要求。本次发布还改进了代理支持、MCP 重连、终端响应速度和 Windows 沙箱可靠性。

GPT-5.6 Sol 现已为符合条件的客户提供 Codex 云端代码评审与质量保障能力。Sol 是 GPT-5.6 系列面向复杂编码、研究、Computer Use 和安全工作的旗舰模型。Codex 云端会自动选择模型；Terra 和 Luna 仍可在受支持的本地与 Web 入口中使用。

为 GPT-5.4 模型退役做好准备

8 月 31 日起，使用 ChatGPT 登录的用户将无法继续在 Codex 中使用 GPT-5.4 和 GPT-5.4 mini。请在工作区默认值、已保存模型设置、托管配置、自定义智能体和计划任务中，把 gpt-5.4 替换为 gpt-5.6-terra，把 gpt-5.4-mini 替换为 gpt-5.6-luna。

让 Codex 检查终端输出
