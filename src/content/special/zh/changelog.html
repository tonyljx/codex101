  • 2026-07-31

    GPT-5.4 和 GPT-5.4 mini 将于 8 月 31 日从 Codex 中退役

    2026 年 8 月 31 日，GPT-5.4 和 GPT-5.4 mini 将不再向使用 ChatGPT 登录的 Codex 用户提供。GPT-5.4 和 GPT-5.4 mini 仍可通过 OpenAI API，以及使用 API key 认证的 Codex 会话使用。

    请切换到推荐的替代模型：

    • 将 gpt-5.4 替换为 gpt-5.6-terra（GPT-5.6 Terra）。
    • 将 gpt-5.4-mini 替换为 gpt-5.6-luna（GPT-5.6 Luna）。

    请在截止日期前更新仍在使用这两个模型的工作区默认设置、已保存的模型设置、托管配置、自定义智能体和定时任务。

    详情见 Codex 模型和工作区模型可用性。

  • 2026-07-30

    浏览器升级、跨仓库评审与图像编辑 26.727

    最新 ChatGPT 桌面 App 更新让浏览、代码评审和编辑生成图像变得更快、更轻松。

    更快浏览和查找上下文

    • 在内建浏览器地址栏中输入内容，可以重新打开浏览历史记录中的页面；没有匹配项时则会搜索 Google。
    • 在 Settings（设置）中管理浏览历史记录，并允许 ChatGPT 在任务需要时搜索你之前访问过的页面。
    • 使用 Chrome extension 提及已打开的 tab，或把页面中高亮的文本带入侧边聊天。
    • 在 Chrome extension 中询问任意 YouTube 视频的内容，并快速获得回答。
    • 右键点击网页并选择 Ask ChatGPT（询问 ChatGPT）。

    进一步了解内建浏览器和 Chrome extension。

    跨仓库评审变更

    查看多文件夹项目中的全部仓库，以及每个仓库的变更行。选择 Review（评审），即可在同一处检查跨仓库 diff，无需在多个独立评审视图之间切换。

    优化生成的图像

    在扩展查看器中打开生成图像，并在 Focused view（聚焦视图） 与 Canvas view（画布视图） 之间切换。你可以跨图像添加评论、选择目标图像并发送定向编辑，而无需离开当前对话。进一步了解图像生成。

    其它改进与 Bug 修复

    • 侧栏新增 Activity view（活动视图），用于查看最近互动或需要关注的聊天。选择铃铛，或按 Cmd/Ctrl+Opt+U 即可切换。
    • 浏览器设置现在只显示受支持的浏览器。
    • 提升 Windows 安装可靠性，尤其是软件包文件路径较长时。
    • 其它性能改进与 Bug 修复。

  • 2026-07-29

    Sign in with ChatGPT（Beta）

    Sign in with ChatGPT 已开始在部分 plugin 和合作伙伴网站中以 Beta 形式逐步推出，首批包括 Airtable、GitLab、HubSpot、Notion、Supabase 和 Vercel。

    从 ChatGPT plugin directory 连接支持的 plugin 时，你可以使用 Sign in with ChatGPT，以更少的步骤创建该服务的账号或关联现有账号。在参与计划的合作伙伴网站中，也可以选择 Sign in with ChatGPT 来创建或访问账号。

    这让你可以更轻松地在 ChatGPT 和 Codex 中开始使用受支持的工具。

    登录时，合作伙伴只会收到你的姓名、电子邮件地址和个人资料图片（如有）。每个 plugin 请求的访问权限仍需单独查看并批准。

  • 2026-07-29

    Codex CLI 0.146.0

    npm install -g @openai/codex@0.146.0

    新功能

    • 可通过 /new 或 /clear 为新会话命名、固定重要对话线程，并在不关闭侧边对话的情况下切换。
    • 支持 Agent Plugins manifest、工作区 plugin 发布，以及适用于 Amazon Bedrock 和 Claude Code 的更多 plugin marketplace。
    • 支持从分页历史中 fork 对话线程，包括不会出现在对话线程列表中的临时 fork。
    • App Server 可通过 WebSocket 连接远程 Code Mode host。
    • 兼容的自定义模型提供商可以启用独立 Web 搜索。
    • 可发现执行器提供的 skill，并安全读取其关联资源，包括用户显式选择的 skill。

    Bug 修复

    • 认证、plugin 下载、MCP 授权、远程执行、WebSocket、重定向和 LM Studio 连接现在都会遵循已配置的代理。
    • 认证或配置变化时会刷新 MCP 连接和 Apps 工具，并在不中断健康连接的情况下重连已关闭的 MCP servers。
    • 在中断、回放、导入和 fork 过程中保留已提交消息、最终响应、失败 turn 错误、导入时间戳和审批设置。
    • 改进终端响应速度与渲染，包括非阻塞中断、键盘处理、窄屏布局、超链接和刷新的 mention 结果。
    • 修复 Windows 导航键，可靠终止沙箱进程树，并在安全评审期间保留代理设置。
    • 在上下文预算紧张时保留更多可用 skill，并在 skill catalog 必须截断时发出警告。

    文档

    • 说明共享 HTTP client、支持代理的连接池和安全的出站请求处理方式。
    • 明确 PathUri 值的 Windows 盘符规范化规则。

    维护

    • 通过 OpenAI 托管的发布基础设施分发 release artifact、channel metadata 和 installer alias，并保留 GitHub fallback。
    • 在打包前签名并公证随附的 macOS helper executable。
    • 减少 App Server 序列化开销和不必要的请求构建分配。
    • 新增企业套餐识别和用于 App 内更新的管理员控制项。
