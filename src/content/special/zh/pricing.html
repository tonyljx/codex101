Codex 定价

ChatGPT Work 和 Codex 已包含在你的 ChatGPT Free、Go、Plus、Pro、Business、Edu 或 Enterprise 套餐中

ChatGPT Work 与 Codex 共享使用量。ChatGPT 中的 ChatGPT Work 使用相同的定价、credits 和使用限制。

Codex 包含在 ChatGPT Free、Go、Plus、Pro、Business、Edu 或 Enterprise 计划中，具体可用功能和额度取决于计划、地区及工作区设置。你也可以使用 API key，并按 API 定价支付实际 token 用量。

邀请朋友和同事

符合条件的用户可以从 App 左下角的个人资料菜单发送 Codex 邀请。符合条件的个人计划选择 Invite a friend（邀请朋友）；符合条件的 Business 工作区选择 Invite a coworker（邀请同事），输入收件人邮箱后发送。

邀请对话框会显示当前奖励、收件人要求、邀请上限，以及当前计划或活动中奖励的过期时间。个人推荐和 Business 推荐使用不同的奖励与资格规则；ChatGPT Enterprise 当前不支持推荐活动。

官方来源记录的 2026 年 6 月 11 日至 6 月 24 日 Plus/Pro 邀请活动现已结束。当期符合条件的用户最多可邀请三位朋友；符合条件的收件人发送第一条 Codex 消息后，双方会获得一个可储存的速率限制重置次数，发放后 30 天内有效。Business 推荐使用另一套共享工作区 credit 奖励；发送邀请前请查看当前条款。

常见问题

Sites 如何计费？

Sites 在公开测试期间包含在符合条件的 ChatGPT 计划中。可用性取决于计划、地区和工作区设置。

我的计划有哪些使用限制？

可以发送多少条消息取决于所用模型、任务的规模与复杂度，以及任务是在本地还是云端运行。小型脚本或常规函数可能只消耗少量额度；较大的项目、长时间运行任务，或需要智能体保留更多上下文的会话，每条消息会明显消耗更多额度。

看起来相似的任务也可能消耗不同额度。模型选择、上下文、推理、工具使用、检索和缓存都会影响使用量，因此不能只用提示词长度估算。

按工作类型选择 GPT-5.6 模型：

  • Sol：面向最困难的工作，包括复杂推理、模糊问题、高级编码和高风险决策。
  • Terra：适合生产任务、报告、文档分析、编码和需要可靠判断的日常主力模型。
  • Luna：针对快速、高吞吐工作优化，例如路由、分类、提取、支持、后台自动化和范围明确的编码任务。

使用灵活定价的 Enterprise/Edu 用户没有固定速率限制，使用量会随 credits 扩展。未使用灵活定价的 Enterprise 和 Edu 计划，在大多数功能上的单席位限制与 Plus 相同。

用量额度会与其他智能体功能共享；相应功能定价生效后会纳入统一限制。目前 Plus 和 Pro 中的 ChatGPT for Excel 已包含在内。

速度配置会提高适用模型的 credit 消耗，也会更快用完包含额度。Fast mode 对支持的模型使用更高 credit 速率，详情见 Speed。图片生成也会计入包含额度；根据质量和尺寸，平均消耗速度约为不含图片生成的类似会话轮次的 3–5 倍。

GPT-5.3-Codex-Spark 目前只向 ChatGPT Pro 用户提供研究预览，发布时不在 API 中提供。它运行在专用低延迟硬件上，因此使用独立额度，限制可能随需求调整。

桌面端 ChatGPT Voice

桌面端 ChatGPT Voice 使用一套按套餐区分的独立额度，以滚动五小时窗口计算。通过 Voice 启动的任务会使用现有 Codex 用量额度。达到任一限制时，ChatGPT 都会提醒你。

桌面端 ChatGPT Voice 使用双工模型：GPT-Live 负责实时对话，GPT-5.6 Terra 则在 App 中启动并协调任务。

  • Plus： 约 15–30 分钟。
  • Pro 5x（100 美元/月）： 约 1–2.5 小时。
  • Pro 20x（200 美元/月）： Voice 使用时长不限。
  • Business： 约 45 分钟。
  • Enterprise / Edu（旧版）： 约 45 分钟。

Voice 使用时长不限并不代表 Codex 任务不限量。通过 ChatGPT Voice 启动的任务仍会使用现有 Codex 用量额度。

对于采用 credit 或按用量付费的 Business、Edu 和 Enterprise 工作区，桌面端 Voice 每分钟约消耗 6 credits。桌面端 ChatGPT Voice 目前不支持 API key。

达到使用限制后会怎样？

如果在一个正在进行的会话轮次中达到使用限制，在公平使用限制允许的范围内，智能体仍可继续完成该轮工作。

达到限制的 ChatGPT Plus 和 Pro 用户可以购买额外 credits，而无需升级现有计划。采用灵活定价的 Business、Edu 和 Enterprise 计划可以购买额外工作区 credits。

接近限制时，也可以切换到更小的模型，让剩余额度维持更久。所有用户还可以使用 API key 运行额外的本地聊天，并按标准 API 价格付费。

图片生成如何计入使用限制？

图片生成与本地消息、云端任务共用通用额度。根据图片质量和尺寸，平均消耗速度约为不包含图片生成的类似会话轮次的 3–5 倍。用完包含额度后，图片生成也会继续消耗 credits。

Free 计划不提供图片生成。通过 API key 使用 Codex 时，图片生成按 API 价格计费，不使用 ChatGPT 套餐额度。

在哪里查看当前使用限制？

可以在 usage dashboard（用量仪表盘） 查看当前限制。在 Codex CLI 的活动会话中，可以使用 /status 查看剩余额度。

建议每隔一到两周检查用量仪表盘，了解使用速度和剩余容量。如果用量高于预期，可以评估更小模型或更聚焦的任务范围是否仍能提供有用结果。

Tokens 和 credits 是什么？

tokens 是 ChatGPT 读写信息时使用的小型单位。提示词、文件、聊天历史、工具结果和回复都会消耗 tokens。

credits 把 token 使用量转换成更容易跟踪和管理的单位。credit 成本会随模型、上下文、推理和工具变化。用完套餐包含额度后，只要仍有 credits，就可以继续工作。

用量按每百万输入 tokens、缓存输入 tokens 和输出 tokens 计算 credits。进一步了解 tokens。

哪些操作计入 Code Review 用量？

只有 Codex 通过 GitHub 执行的评审才计入 Code Review 用量，例如在 PR 中通过 @Codex 请求评审，或为仓库启用自动评审。在本地或 GitHub 之外运行的评审计入通用使用限制。

如何让使用限制维持更久？

上面的使用限制和 credits 都是平均费率。可以通过以下方式提高额度利用率：

  • 控制提示词规模。 给智能体的指令应准确，但应移除不必要上下文。
  • 限制来源材料。 只提供相关文件，并在可能时收窄来源或日期范围。
  • 让输出匹配实际需要。 明确受众、格式和长度，并把必需工作与可选润色分开。
  • 减小 AGENTS.md。 大型项目可以通过在仓库中分层放置 AGENTS.md，控制注入的上下文量。
  • 限制 MCP server 数量。 每个 MCP server都会增加上下文和额度消耗；不需要时应禁用。
  • 为常规任务选择更小模型。 根据当前模型，切换到 GPT-5.6 Terra 或 GPT-5.6 Luna 可能延长本地消息额度。

关于如何选择和限定任务范围，见高效使用 Work。
