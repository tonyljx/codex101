## Mulai dengan Skill & Plugin

Mulailah dari hasil yang diinginkan, lalu berikan file, konteks, dan batasan yang diperlukan. Biarkan Codex memeriksa proyek asli dan memverifikasi hasil setelah setiap langkah penting.

<Example>

“Periksa situs Astro ini, tambahkan multibahasa tanpa mengubah desain, lalu verifikasi di perangkat seluler.”

</Example>

## Alur kerja yang andal

1. Jelaskan hasil dan kriteria penerimaan
2. Periksa file terkait dan konvensi yang ada
3. Lakukan perubahan dan pemeriksaan sesuai risiko
4. Tinjau hasil, perbedaan, dan langkah berikutnya

## Ketika terjadi masalah

Simpan pesan kesalahan lengkap, periksa direktori kerja dan izin, lalu perkecil masalah menjadi langkah reproduksi minimum. Utamakan keluaran nyata daripada dugaan.

```bash
npm run check
npm run build
```
