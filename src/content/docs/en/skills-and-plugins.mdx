## Start with Skills & Plugins

Start with the outcome you want, then provide the necessary files, context, and constraints. Let Codex inspect the real project and verify the result after each meaningful step.

<Example>

“Inspect this Astro site, add multilingual routing without changing the visual system, and verify it on mobile.”

</Example>

## A reliable workflow

1. Describe the outcome and acceptance criteria
2. Inspect the relevant files and existing conventions
3. Make the change and run checks proportional to the risk
4. Review the result, diff, and next step

## When something goes wrong

Keep the complete error message, confirm the working directory and permissions, then reduce the problem to the smallest reproducible step. Prefer real output over guesses.

```bash
npm run check
npm run build
```
