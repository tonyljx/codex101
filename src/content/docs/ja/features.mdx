## 機能 を始める

最初に求める成果を明確にし、必要なファイル、背景、制約を共有します。Codex に実際のプロジェクトを確認させ、重要な手順ごとに結果を検証します。

<Example>

「この Astro サイトを調べ、見た目を変えずに多言語対応し、モバイルでも確認してください。」

</Example>

## 信頼できるワークフロー

1. 成果と受け入れ基準を説明する
2. 関連ファイルと既存の規約を確認する
3. 変更し、リスクに応じたチェックを実行する
4. 結果、差分、次の手順を確認する

## 問題が起きたとき

エラー全文を残し、作業ディレクトリと権限を確認して、最小の再現手順まで絞り込みます。推測より実際の出力を優先します。

```bash
npm run check
npm run build
```
