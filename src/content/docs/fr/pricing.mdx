## Commencer avec Tarifs

Décrivez d’abord le résultat attendu, puis fournissez les fichiers, le contexte et les contraintes nécessaires. Laissez Codex examiner le vrai projet et vérifier chaque étape importante.

<Example>

« Examine ce site Astro, ajoute le multilingue sans modifier son design et vérifie la version mobile. »

</Example>

## Un flux de travail fiable

1. Décrire le résultat et les critères de validation
2. Examiner les fichiers et conventions concernés
3. Effectuer la modification et les contrôles adaptés au risque
4. Relire le résultat, les différences et la prochaine étape

## En cas de problème

Conservez le message d’erreur complet, vérifiez le dossier de travail et les droits, puis réduisez le problème au plus petit cas reproductible. Préférez les sorties réelles aux suppositions.

```bash
npm run check
npm run build
```
