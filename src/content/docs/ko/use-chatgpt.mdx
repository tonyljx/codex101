## ChatGPT 사용 시작하기

먼저 원하는 결과를 분명히 하고 필요한 파일, 배경, 제약을 제공하세요. Codex가 실제 프로젝트를 확인하고 중요한 단계마다 결과를 검증하게 하세요.

<Example>

“이 Astro 사이트를 확인하고 기존 디자인을 유지한 채 다국어를 추가한 뒤 모바일에서 검증해 주세요.”

</Example>

## 신뢰할 수 있는 워크플로

1. 결과와 승인 기준 설명
2. 관련 파일과 기존 규칙 확인
3. 변경 후 위험에 맞는 검사 실행
4. 결과, 차이, 다음 단계 검토

## 문제가 발생했을 때

전체 오류 메시지를 보존하고 작업 디렉터리와 권한을 확인한 뒤 최소 재현 단계로 줄이세요. 추측보다 실제 출력을 우선하세요.

```bash
npm run check
npm run build
```
