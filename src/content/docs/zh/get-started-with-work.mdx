<h2 id="introducing-chatgpt-work">认识 ChatGPT Work</h2>

ChatGPT Work 是把真实工作委派给 ChatGPT 的一种方式。

需要答案、解释、头脑风暴或简短草稿时，使用 Chat；需要 ChatGPT 完成一项结果明确的任务时，使用 ChatGPT Work，例如简报、演示文稿、分析、定期更新、工作流，或可以评审和使用的文件。更多信息见 [Chat 与 ChatGPT Work 的配合方式](/docs/use-chatgpt)。

ChatGPT Work 可以使用你的文件、plugins 和已批准工具来检索信息、创建成品文件、运行工作流，并完成可供评审的工作。你可以跟踪进度、回答问题、调整方向，并审批重要操作。

在[桌面 App](/docs/app) 中，当相应工具可用时，ChatGPT Work 还可以使用本地文件、Apps 和浏览器。

如果你一直使用 Codex 处理非编码工作，可以继续留在 Codex，也可以改用 ChatGPT Work。ChatGPT Work 具备相同的核心能力，但交互体验更适合日常工作。

## 第一个任务可以尝试什么

<Video src="https://cdn.openai.com/devhub/videos-learn/selectnoonboarding.mp4?v=dda6f24633bd" />

先切换到 **Work**，然后再挑选第一项任务。好的任务通常有清晰结果、少量来源材料，以及可以检查的输出。

### 选择本地或云端工作

在桌面 App 中，打开输入框里标为 **Work locally（在本地工作）** 的控件。如果其中显示 **Cloud（云端）** 选项，可在希望 ChatGPT Work 于关闭 App 或电脑关机后继续运行，或者希望从 Web 或移动 App 继续聊天时选择它。如果任务需要使用电脑上的文件或 Apps，则继续使用 **Work locally**。

云端也适合需要持续研究或检查网站的计划任务，因为这些运行不依赖电脑保持唤醒。

<h2 id="best-practices-for-using-work">使用 ChatGPT Work 的最佳实践</h2>

当你希望 ChatGPT 完成任务、创建文件，或持续管理工作时，使用 ChatGPT Work。它适合以下任务：

- 使用多个来源、plugins、工具或步骤。
- 如果手动完成，会花费不少时间。
- 产生需要评审、编辑或复用的结果。
- 需要随时间重复、监控或更新。

要获得更好的结果，请告诉 ChatGPT：你需要什么结果、应使用哪些来源或 plugins、必须遵循哪些约束、怎样才算做好，以及何时应停下来等待评审或审批。

与其只说：

<CodeBlock code="Make me a presentation about our customer research." />

不如补充受众、来源、结构、事实核对要求与完成标准：

<PromptCard prompt="Review the attached interview notes and survey results. Create an eight-slide presentation for the product leadership meeting. Focus on the three most common customer problems, include supporting evidence, separate findings from recommendations, and flag any claims that are not well supported. Use @Google Drive for the source docs. Return a draft for my review before treating it as final." />

更多信息见 [ChatGPT Work 提示词](/docs/prompting#prompting-for-work)。

## 添加 plugins，获得更多上下文和更好结果

plugins 可以把 ChatGPT Work 连接到团队使用的工具，例如 Slack、Google Drive、SharePoint、电子邮件、日历、客户关系管理系统和项目跟踪器。

<h2 id="use-chatgpt-work-efficiently">高效使用 ChatGPT Work</h2>

ChatGPT Work 最适合包含多个步骤、来源或工具，或需要完整交付物的重要任务。ChatGPT 代你完成的事情越多，较长或复杂的任务可能使用越多 credits。判断价值时，应关注完成结果，而不是提示词数量。

通过设置有用的边界让任务保持聚焦，例如：“use only these sources,” “compare the top five options,” 或 “stop before sending anything.”

对于快速提问、简短改写，以及只需要建议的决策，请改用 Chat。

更多建议见[高效使用 ChatGPT Work](/docs/prompting#prompting-for-work)。
