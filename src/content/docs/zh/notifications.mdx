通知会在工作需要关注时提醒你。具体控制项和送达渠道会因使用入口而异。

## 配置桌面通知

打开 [**Settings（设置）**](/docs)，选择会话轮次完成提醒的显示方式：从不显示、仅在 ChatGPT 位于后台时显示，或始终显示。你还可以分别开启或关闭权限通知和问题通知。操作系统可能会要求你向 ChatGPT 桌面 App 授予通知权限。

### 在 Activity 视图中跟踪聊天

当 **Activity（活动）** 可用时，选择侧边栏中的铃铛，可以查看未读、正在运行或等待你回复的聊天。你也可以在 macOS 上按 <kbd>Cmd</kbd>+<kbd>Option</kbd>+<kbd>U</kbd>，或在 Windows 上按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>U</kbd>，打开或关闭 Activity 视图。

使用视图中的选项选择要显示的聊天。可用选项取决于当前入口，可能包括 **Work**、**Chat**、**Pinned（已置顶）** 和 **Scheduled（计划任务）**。还可以选择 **Mark all as read（全部标为已读）** 清除未读项。

<span id="follow-task-activity-with-a-pet"></span>

### 使用 Pet 跟踪聊天活动

在 ChatGPT 桌面 App 中，浮动 Pet 是你在其他 App 中工作时跟踪聊天活动的另一种方式。它可以显示聊天处于 **Running（运行中）**、**Needs input（需要输入）**、**Ready（就绪）** 或 **Blocked（受阻）** 状态。

参见 [Pets](/docs/pets?surface=app)，了解如何选择 Pet、理解状态或创建自己的 Pet。
