ChatGPT 工作区的用量限制和支出控制适用于该工作区套餐涵盖且符合条件的活动。根据套餐不同，其中可能包括部分 Codex 活动。这些控制并不是一套通用于所有 Codex 场景的限制系统，也不管理 OpenAI API Platform 的计费。

如需了解完整的管理模型，请参见[角色与工作区权限](/docs/enterprise/roles-and-workspace-permissions)。

## 确认这些控制何时适用

在以下情况下，应检查 ChatGPT 工作区的用量控制：

-   组织协议使用共享或购买的 ChatGPT 工作区 credits。
-   符合条件的 Codex 活动会消耗这些 credits。
-   管理员需要使用当前套餐支持的用户级使用约束、工作区级支出控制或用量通知。

用量控制不负责配置功能授权或权限，但当额度耗尽时，符合条件的功能可能会暂停访问。它们不会影响来源系统中的权限，也不管理 Platform API 的用量或计费。
