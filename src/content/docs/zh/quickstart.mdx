    <section className="quickstart-v2__panel doc-content" id="quickstart-panel-1" role="tabpanel" aria-labelledby="quickstart-tab-1" data-surface-panel="1">
      <span id="desktop-app" className="quickstart-v2__panel-anchor" aria-hidden="true"></span>

ChatGPT 桌面 App 支持 Windows 和 macOS，适合处理项目、本地文件、长时间任务和快速聊天。

<ol className="doc-workflow-steps">
  <li>
    <p><strong>安装 ChatGPT 桌面 App。</strong> 前往[桌面 App 页面](/docs/app)，选择适用于当前操作系统的版本。</p>
  </li>
  <li>
    <p><strong>打开 ChatGPT 桌面 App 并登录。</strong> 使用 ChatGPT 账号登录。你也可以通过 API key 使用 Codex，但[部分功能可能不可用](/docs/pricing#feature-availability)。</p>
  </li>
  <li>
    <p><strong>选择 ChatGPT 的工作位置。</strong> 开始一个聊天、创建项目或打开文件夹。ChatGPT 可以读取并修改你所选文件夹中的文件。进一步了解[聊天与项目](/docs/projects)。</p>
  </li>
  <li>
    <p><strong>开始聊天。</strong></p>
    <ul>
      <li>对于研究、分析，或文档、演示文稿、电子表格和 Sites 等交付物，请选择 <strong>ChatGPT</strong>，再在新聊天页面顶部、输入框上方切换到 <strong>Work</strong>。</li>
      <li>对于需要代码库上下文和开发者工具的软件开发工作，请从 ChatGPT 下拉菜单中选择 <strong>Codex</strong>。</li>
      <li>对于简短问题或普通聊天，请选择 <strong>ChatGPT</strong>，再从新聊天页面顶部、输入框上方的切换器中选择 <strong>Chat</strong>。在 Codex 中，将指针移到 <strong>New chat</strong> 上，再选择右侧的 <strong>Quick chat</strong> 图标。</li>
    </ul>
    <p>进一步了解[如何使用 ChatGPT](/docs/use-chatgpt)。</p>
  </li>
  <li className="quickstart-v2__message-step">
    <p><strong>发送第一条消息。</strong> 描述目标，并附上 ChatGPT 所需的文件或上下文。可以从以下示例开始：</p>
    <PromptPicker
      labels={["准备决策", "分析电子表格", "改进这个应用"]}

        "Review the reports and notes in this project, compare the options, and create a one-page decision memo with a recommendation, risks, open questions, and source links.",
        "Combine the spreadsheets in this folder, clean inconsistent records, identify the most important trends, and create a concise report with charts and plain-English takeaways.",
        "Inspect this app, identify one high-impact usability improvement, implement it, update the relevant tests, and verify the result on mobile and desktop."
      ]}
      pickerLabel="选择示例提示词"
      copyLabel="复制当前提示词"
      copiedLabel="已复制提示词"
      exampleSuffix="示例"
    />
    <p>继续探索更多[使用场景](https://learn.chatgpt.com/use-cases)。</p>
  </li>
</ol>

ChatGPT 可直接在 Web 上使用，其中包括 Chat 和 ChatGPT Work。

<ol className="doc-workflow-steps">
  <li>
    <p><strong>打开 ChatGPT 并登录。</strong> 前往 [chatgpt.com](https://chatgpt.com)，使用 ChatGPT 账号登录。</p>
  </li>
  <li>
    <p><strong>开始聊天。</strong></p>
    <ul>
      <li>选择 <strong>Chat</strong>，以对话方式提出问题、探索想法或深入讨论某个主题。</li>
      <li>选择 <strong>Work</strong>，开展研究、分析信息，并创建文档、演示文稿、电子表格、Sites 或其他完成度较高的交付物。</li>
    </ul>
    <p>进一步了解[如何使用 ChatGPT](/docs/use-chatgpt)。</p>
  </li>
  <li>
    <p><strong>选择 ChatGPT 的工作位置。</strong> 开始聊天或选择项目。项目可以包含聊天、文件和指令。</p>
  </li>
  <li className="quickstart-v2__message-step">
    <p><strong>发送第一条消息。</strong> 描述目标，并附上 ChatGPT 所需的文件或上下文。可以从以下示例开始：</p>
    <PromptPicker
      labels={["做出决策", "每日简报", "规划活动"]}

        "Every weekday at 8:00 a.m., review my connected calendar and recent messages, then send me a briefing with today's priorities, meeting prep, replies I owe, and blockers.",
        "Help me plan my event. Ask me about the occasion, guests, date, location, budget, and anything else you need. Then create a timeline, budget, invitation copy, and checklist, and publish a Site I can use to invite guests and collect RSVPs."
      ]}
      pickerLabel="选择示例提示词"
      copyLabel="复制当前提示词"
      copiedLabel="已复制提示词"
      exampleSuffix="示例"
    />
  </li>
</ol>
