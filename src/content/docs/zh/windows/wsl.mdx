当你使用 WSL2 时，Codex 在 Linux 环境中运行，而不是使用 本机[Windows沙箱](/docs/windows/windows-sandbox)。当你需要 Linux 原生时选择 WSL2 工具、你的仓库和开发人员工作流已存在于 WSL2 中，或者 本机 Windows 沙箱模式都不适用于你的环境。

WSL1 通过 Codex `0.114` 支持。从 Codex `0.115` 开始，Linux 沙箱已移至 `bubblewrap`，因此不再支持 WSL1。

## 从 WSL 内部启动 VS Code

有关分步说明，请参阅[官方 VS Code WSL 教程](https://code.visualstudio.com/docs/remote/wsl-tutorial)。

### 先决条件

-   安装了 WSL 的 Windows。要安装 WSL，请以管理员身份打开 PowerShell，然后运行 ​​`wsl --install`（Ubuntu 是常见选择）。
-   安装了 [WSL 扩展](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-wsl) 的 VS Code。

### 从 WSL 终端打开 VS Code

<CodeBlock code={"# From your WSL shell\ncd ~/code/your-project\ncode ."} language="bash" />

这将打开 WSL 远程窗口，根据需要安装 VS Code 服务器，并确保集成终端在 Linux 中运行。

### 确认你已连接到 WSL

-   查找显示 `WSL: <distro>` 的绿色状态栏。
-   集成终端应显示Linux路径（例如`/home/...`）而不是`C:\`。
-   你可以通过以下方式验证：

<CodeBlock code={"  echo $WSL_DISTRO_NAME"} language="bash" />

这将打印你的发行版名称。

如果状态栏中没有看到“WSL: ...”，请按 <kbd>Ctrl+Shift+P</kbd>，选择 `WSL: Reopen Folder in WSL`，并将你的仓库保存在 `/home/...` 下（不是 `C:\`) 以获得最佳性能。

如果 Windows 应用或项目选择器未显示你的 WSL 仓库，请键入 `\\wsl$` 进入文件选择器或资源管理器，然后导航到你的 发行版的主目录。

## 将 Codex CLI 与 WSL 结合使用

从提升的 PowerShell 或 Windows 终端运行这些命令：

<CodeBlock code={"# Install default Linux distribution (like Ubuntu)\nwsl --install\n\n# Start a shell inside Windows Subsystem for Linux\nwsl"} language="powershell" />

然后从 WSL shell 运行这些命令：

<CodeBlock code={"# Install and run Codex in WSL\ncurl -fsSL https://chatgpt.com/codex/install.sh | sh\ncodex"} language="bash" />

## 在 WSL 中处理代码

-   在 `/mnt/c/...` 这样的 Windows 安装路径中工作可能比在 Windows 本机路径中工作慢。将仓库保存在 Linux 主目录下（例如 `~/code/my-app`），以加快 I/O 速度并减少符号链接和权限问题：

<CodeBlock code={"  mkdir -p ~/code && cd ~/code\n  git clone https://github.com/your/repo.git\n  cd repo"} language="bash" />

-   如果你需要 Windows 访问文件，它们位于资源管理器中的 `\\wsl$\Ubuntu\home\&lt;user&gt;` 下。

## 故障排除和常见问题解答

大型仓库在 WSL 中感觉很慢

-   确保你不在 `/mnt/c` 下工作。将仓库移至 WSL（例如，`~/code/...`）。
-   如果需要，增加 WSL 的内存和 CPU；将 WSL 更新到最新版本：

<CodeBlock code={"  wsl --update\n  wsl --shutdown"} language="powershell" />

WSL 中的 VS Code 找不到 codex

验证二进制文件是否存在并且位于 WSL 内的 `PATH` 上：

<CodeBlock code={"which codex || echo \"codex not found\""} language="bash" />

如果未找到二进制文件，请按照 [Codex CLI 设置说明](#use-codex-cli-with-wsl) 操作。
