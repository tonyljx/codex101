OpenAI 以开源方式开发 Codex 的关键组成部分。这些工作都托管在 GitHub 上，因此你可以跟踪进展、提交问题，并贡献改进。

如果你维护的是广泛使用的开源项目，或者你想提名那些长期维护重要开源项目的维护者，也可以申请 [Codex 开源支持计划](https://developers.openai.com/community/codex-for-oss)。该计划可能提供 API 额度、带 Codex 的 ChatGPT Pro，以及定向开放的 Codex 安全访问权限。

<h2 id="在哪里报告问题和提出功能请求">在哪里报告问题和提出功能请求</h2>

请根据问题所属组件使用对应的 GitHub 仓库：

- Codex bug 报告和功能请求：[openai/codex/issues](https://github.com/openai/codex/issues)
- Codex Security CLI 与 TypeScript SDK bug 报告和功能请求：[openai/codex-security/issues](https://github.com/openai/codex-security/issues)
- 讨论论坛：[openai/codex/discussions](https://github.com/openai/codex/discussions)

提交 issue 时，请说明正在使用的组件（CLI、SDK、IDE 扩展、Codex 云端或 Codex Security），并尽量附上版本号。
