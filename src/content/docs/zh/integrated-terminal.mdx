ChatGPT 桌面 App 中的每个聊天都包含一个终端，其作用域限定在当前项目或工作树。点击 App 右上角的终端图标，或按 <kbd>Ctrl</kbd>+<kbd>\`</kbd> 即可打开。

## 运行并验证项目

使用终端验证改动、运行脚本和执行 Git 操作，无需切换 App。ChatGPT 可以读取当前终端输出，因此它能在与你协作时检查正在运行的开发服务器，或引用构建失败信息。

常见命令包括：

-   `git status`
-   `git pull --rebase`
-   `pnpm test` 或 `npm test`
-   `pnpm run lint` 或其他项目专用检查

## 创建可复用 actions

如果某条命令需要经常运行，可以在[本地环境](/docs/environments/local-environment#actions)中把它定义为 action。Actions 会作为快捷入口显示在 ChatGPT 桌面 App 中，并通过集成终端运行。

<kbd>Cmd</kbd>+<kbd>K</kbd> 打开 App 命令面板，不会清空终端。若要清空终端，请按 <kbd>Ctrl</kbd>+<kbd>L</kbd>。
