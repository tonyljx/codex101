斜杠命令让你无需离开聊天输入框就能执行操作。可用命令会因运行环境和访问权限而异。

## 使用斜杠命令

1.  在聊天输入框中输入 `/`。
2.  从列表中选择命令，或继续输入以筛选，例如 `/status`。

你也可以在聊天输入框中输入 `$`，显式调用 skill。详见 [Skills 与 Plugins](/docs/skills-and-plugins)。

已启用的 skills 也会出现在斜杠命令列表中。自定义提示词会显示为 `/prompts:<name>` 命令。

## 使用 `/goal` 设置或管理目标

<Screenshot src="/images/codex/app/goal-dialog-light.webp" darkSrc="/images/codex/app/goal-dialog-dark.webp" alt="ChatGPT 界面截图：ChatGPT desktop app goal progress controls above the composer" />

在 App 输入框中使用 `/goal` 启动 Goal mode（目标模式）。目标是 ChatGPT 持续推进的任务目标，直到任务完成、暂停或需要更多输入。若要先与 ChatGPT 一起明确目标，可先使用 `/plan`，再用 `/goal` 设置完善后的目标。

目标生效后，App 会在输入框上方显示进度。你可以使用进度行中的按钮暂停或恢复目标、编辑目标文字或清除目标，无需再输入斜杠命令。目标运行期间仍可以通过后续消息继续引导 ChatGPT。

有关有效目标的写法，请参阅[目标模式](/docs/prompting#goal-mode)。
