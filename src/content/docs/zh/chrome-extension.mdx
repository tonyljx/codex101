Chrome extension 可以让 ChatGPT 控制你的 Chrome 浏览器。ChatGPT 能够读取或操作你已经登录的网站，例如 LinkedIn、Salesforce、Gmail 或内部工具。

如果想让 ChatGPT 改用内置浏览器，请使用 `@Browser`。[内置浏览器](https://help.openai.com/en/articles/20001277-using-the-built-in-browser-in-the-chatgpt-desktop-app)支持登录，并把浏览工作保留在 ChatGPT 内，不使用你的 Chrome 配置档案。

ChatGPT 也可以根据任务需要切换工具：有专用集成时使用 plugins，需要已登录浏览器上下文时使用 Chrome，处理 localhost 时使用内置浏览器。

<Callout kind="warning">

**警告：**请把页面内容视为不可信上下文，并在允许 ChatGPT 继续前检查网站。

</Callout>

## 从 Chrome 使用 ChatGPT

在正在浏览的页面旁打开 ChatGPT，可以询问页面内容，也可以继续执行需要同时使用页面上下文、本地文件和连接器的任务。任务需要时，ChatGPT 可以使用你已打开标签页的上下文。

1.  打开要处理的页面。
2.  在 Chrome 工具栏或 \*\*Extensions（扩展程序）\*\*菜单中选择 ChatGPT。在 macOS 上，也可以按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>.</kbd>。
3.  询问页面相关问题，或交给 ChatGPT 一项任务。

面板会跟随你打开它的标签页。从 Chrome 发起的聊天会出现在 ChatGPT App 中，你也可以从 Chrome 打开最近的 ChatGPT 聊天，因此可以在两个入口之间继续工作。

**Chrome 中的 ChatGPT**

侧边面板会附着在打开它的标签页上，并可在需要时使用已打开标签页的上下文。

## 把标签页和所选文本带入聊天

当你希望 ChatGPT 使用某个页面作为上下文时，可以在 side chat 中提及已打开的 Chrome 标签页。你也可以高亮页面中的文本，并把所选内容带入聊天，直接询问某个段落，而不必复制整个页面。

如果要从页面发起请求，请右键点击页面并选择 **Ask ChatGPT**。side chat 会带着相关页面上下文打开，你可以继续在 Chrome 中处理请求。

### 询问 YouTube 视频内容

打开 YouTube 视频，然后在 Chrome side chat 中提问。视频提供字幕时，ChatGPT 可以使用带时间戳的 transcript 解释、总结内容或回答问题。

请把网页内容、所选文本和视频 transcript 视为不可信上下文。要求 ChatGPT 使用这些信息或据此执行操作前，应先检查页面和请求的权限。

## 设置 Chrome extension

在 ChatGPT 桌面 App 中打开 Plugins Directory，并安装 **Chrome**。目前不支持其他基于 Chromium 的浏览器。按照设置流程：

1.  安装 [Chrome extension](https://chromewebstore.google.com/detail/chatgpt/hehggadaopoacecdllhhajmbjkdcmajg)。
2.  批准 Chrome 的权限提示。
3.  打开 Chrome，确认 ChatGPT side chat 能够加载。

## 从 ChatGPT 发起 Chrome 任务

完成 plugin 设置后，在 ChatGPT Work 或 Codex 中开始新聊天。当任务需要网站，且你已经登录 Chrome 时，ChatGPT 可以自动使用 Chrome；你也可以在提示词中直接调用：

<CodeBlock code={"@Chrome open Salesforce and update the account from these call notes."} language="text" />

如果 Chrome 尚未打开，ChatGPT 可以将其打开。Chrome 浏览器任务会在 Chrome 标签页组中运行，让同一聊天的工作保持在一起。

## 控制网站访问

默认情况下，ChatGPT 与每个新网站交互前都会询问。确认提示按网站 host（例如 `example.com`）确定范围。

ChatGPT 请求使用网站时，可以根据任务和可接受的风险选择：

-   **Allow once（允许一次）**：只允许 ChatGPT 使用网站一次。
-   **Allow for this site（允许此网站）**：以后使用同一网站时不再询问。
-   **Allow for all sites（允许所有网站）**：使用任何网站前都不再询问。
-   **Decline（拒绝）**：阻止 ChatGPT 使用该网站。

### 管理允许和阻止的网站

在 ChatGPT 桌面 App 中，进入 **Settings（设置）** > **Computer Use**，然后在 **Google Chrome** 旁选择 **Manage（管理）**，即可管理域名 allowlist 和 blocklist。allowlist 包含 ChatGPT 无需再次询问即可使用的域名；blocklist 包含 ChatGPT 不应使用的域名。

从 allowlist 移除域名后，ChatGPT 下次使用前会重新询问。从 blocklist 移除后，ChatGPT 可以重新请求访问，而不再直接将其视为被阻止。

#### Allow for all sites（允许所有网站）— 高风险

选择后，ChatGPT 使用网站前不再请求确认。只有在你信任 ChatGPT 使用 Chrome 中打开的任何网站时，才选择此项。

#### Browser history（浏览器历史记录）— 高风险

浏览器历史记录可能包含敏感遥测、内部 URL、搜索词，以及已登录设备上的 Chrome 会话活动。如果允许 ChatGPT 访问浏览器历史，相关条目可能成为任务上下文的一部分。恶意或误导性页面内容会增加 ChatGPT 把这些数据复制到非预期位置的风险。

ChatGPT 会在需要使用浏览器历史时询问。历史访问只针对当前请求，而且没有 always-allow 选项。

## 数据与安全

### Chrome extension 权限

安装扩展时，Chrome 会要求接受扩展权限，可能包括：

-   访问页面 debugger。
-   读取和更改所有网站上的全部数据。
-   读取和更改所有已登录设备上的浏览历史。
-   显示通知。
-   读取和更改书签。
-   管理下载。
-   与配套的原生应用通信。
-   查看和管理标签页组。

这些 Chrome 权限使扩展具备操作浏览器工作流的能力。在任务中使用网站或浏览器历史前，ChatGPT 仍会应用自己的确认、设置、allowlist 和 blocklist。

### Memories

Computer Use 遵循你的 Memories 设置。启用后，ChatGPT 在 Chrome 中工作时可以使用相关已保存记忆；关闭后，浏览器控制不会使用记忆。

### OpenAI 会存储哪些浏览活动

OpenAI 不会通过扩展单独保存一份完整的 Chrome 操作记录。只有浏览活动成为 ChatGPT 上下文的一部分时才会被保存，例如 ChatGPT 从页面读取的文本、截图、工具调用、摘要、消息或聊天中包含的其他内容。

你的 ChatGPT 数据控制会应用于上下文中处理的内容。除非任务确实需要，而且你会在场检查每次提示，否则不要通过浏览器任务发送 secrets 或高度敏感数据。

## 故障排查

如果 ChatGPT 无法连接 Chrome，先确认它要访问的网站没有被 Settings 中的 blocklist 阻止。如果网站未被阻止，请依次检查：

1.  更新 ChatGPT 桌面 App。如果安装了多个 ChatGPT 或 Codex 桌面 App，请全部更新，或移除不再使用的副本。
2.  关闭 ChatGPT side panel，重启 Chrome，再从 Chrome 工具栏或 \*\*Extensions（扩展程序）\*\*菜单重新打开扩展。确认 side chat 能够加载。如果无法加载或提示缺少 native host，请从 ChatGPT 桌面 App 的 **Plugins** 中移除并重新添加 Chrome plugin，再重新完成设置流程。
3.  在 App 中选择 ChatGPT 并在切换器中开启 Work，或选择 Codex。打开 **Plugins**，确认 Chrome plugin 已开启；如果关闭，请开启后重试。
4.  确认使用的是安装扩展时的同一个 Chrome 配置档案。如果有多个配置档案，请在当前配置档案中安装并启用扩展。
5.  在 ChatGPT Work 或 Codex 中开始新聊天并重试，以清除聊天特定的连接状态。
6.  重启 ChatGPT 桌面 App 后重试。如果仍无法连接，请卸载 Chrome extension，从 **Plugins** 移除并重新添加 Chrome plugin，再重新完成设置流程。
7.  如果 side chat 能够加载，但 ChatGPT 仍无法使用 Chrome，请在 App 中运行 `/feedback`，联系支持时附上聊天 ID。

### 上传文件

如果 Chrome 任务需要从电脑上传文件，请允许 Chrome extension 访问 file URLs：

1.  在 Chrome 工具栏中打开扩展图标，然后点击 **Manage Extensions（管理扩展程序）**。
2.  在扩展卡片中点击 **Details（详情）**。
3.  开启 **Allow access to file URLs（允许访问文件网址）**。

更改设置后，重新开始 Chrome 任务。
