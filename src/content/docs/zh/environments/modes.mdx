在 ChatGPT 桌面 App 中打开 ChatGPT 下拉菜单，然后选择 **Codex**。启动 Codex 聊天时，需要选择运行位置：

-   **Local（本地）：** 直接在当前项目目录中工作。
-   **Worktree（工作树）：** 在 Git 工作树中隔离改动。[了解详情](/docs/environments/git-worktrees)。
-   **Cloud（云端）：** 在已配置的云端环境中远程运行。

**Local（本地）** 和 **Worktree（工作树）** 聊天都会在你的电脑上运行。

要了解完整术语和概念，请阅读[概念部分](/docs/prompting)。
