电商是非常适合 Skill 的行业，因为大量工作都有同一个特点：**输入每天在变，但分析方法和输出模板高度重复。**

<span id="best-use-cases"></span>

## 最适合 Skill 的电商工作

优先考虑下面几类：

- 商品评论 / 差评分析；
- 竞品 Listing 对比；
- 商品标题和卖点优化；
- 广告周报与异常分析；
- 客服问题归类；
- 新品调研；
- 活动复盘；
- 多语言商品内容本地化。

它们通常都满足：重复发生、有固定步骤、希望结果一致。

<span id="recommended-stack"></span>

## 推荐 Skill 组合

### 1. Review Analyzer

**推荐指数：★★★★★**

这是最值得电商团队自己创建的 Skill 之一。

建议固定流程：

```text
读取评论
→ 去除无信息评论
→ 按问题分类
→ 统计频率
→ 找代表性原话
→ 判断影响程度
→ 区分产品 / 物流 / 客服问题
→ 给改进优先级
```

重点是避免 AI 只做情绪总结，而是真正把评论变成产品和运营输入。

### 2. Listing Optimizer

**推荐指数：★★★★☆**

不要只写“优化一下 Listing”。

更好的 Skill 应该保存：

- 平台字段要求；
- 品牌语气；
- 核心关键词；
- 禁止夸大内容；
- 标题长度；
- Bullet 结构；
- 不同市场的本地化规则。

这样每个 SKU 都可以复用同一套标准。

### 3. Competitor Research

**推荐指数：★★★★☆**

竞品 Skill 可以固定比较：

- 定位；
- 价格；
- 核心卖点；
- 评论里最常见的优缺点；
- 页面结构；
- 促销；
- 差异化机会。

如果再接网页浏览或数据工具，价值会更高。

### 4. Ad Performance Review

**推荐指数：★★★★★**

广告数据最适合分析型 Skill。

建议要求：

```text
先检查花费 / 展现 / 点击 / CTR / CVR / CPA / ROAS
→ 找环比异常
→ 下钻 Campaign / Ad Group / Creative
→ 判断量的问题还是效率的问题
→ 区分数据事实和原因假设
→ 给预算与素材动作建议
```

### 5. Spreadsheet Skill

**推荐指数：★★★★★**

很多电商数据最终还是 CSV / Excel。

表格类 Skill 可以负责：

- 清洗导出数据；
- 合并多表；
- 计算指标；
- 生成透视分析；
- 图表；
- 输出周报底表。

如果你的团队每周都在手工整理相同报表，这通常是最先应该自动化的地方。

<span id="workflow"></span>

## 三个高频工作流

### 工作流 A：每周广告复盘

```text
导出平台数据
→ Spreadsheet Skill 清洗
→ Ad Review Skill 找异常
→ Creative Skill 总结素材表现
→ Weekly Report Skill 输出复盘
```

### 工作流 B：新品上架

```text
竞品研究
→ 用户评论洞察
→ 定位与卖点
→ Listing Skill
→ 图片 / 素材 Brief
→ 上线前 QA
```

### 工作流 C：差评驱动产品改进

```text
抓取 / 导出评论
→ Review Analyzer
→ 高频问题聚类
→ 找代表性评论
→ Product Insight Skill
→ 输出产品改进优先级
```

## 最值得自己做的 Skill

电商 Skill 的价值通常来自**你自己的业务规则**，所以这里比“安装别人的 Skill”更重要。

| 自定义 Skill | 建议沉淀内容 |
| --- | --- |
| `amazon-review-analyzer` | 评论分类、频率、优先级、代表性证据 |
| `listing-writer` | 品牌语气、关键词、字段限制、禁用词 |
| `ad-weekly-review` | 你的 KPI、异常阈值、下钻顺序、报告模板 |
| `competitor-monitor` | 竞品名单、价格/卖点/活动监控项 |
| `customer-voice` | 客服工单与评论统一分类体系 |
| `localization-review` | 多语言表达、单位、文化和合规检查 |

一个实用原则：

> **不要做“万能电商运营 Skill”，而要把评论、Listing、广告、竞品拆成不同 Skill。**

拆开后每个 Skill 更容易触发准确，也更容易评估效果。
