## Bắt đầu với Bảo mật

Hãy bắt đầu bằng kết quả bạn muốn, sau đó cung cấp tệp, bối cảnh và ràng buộc cần thiết. Để Codex kiểm tra dự án thực và xác minh sau mỗi bước quan trọng.

<Example>

“Kiểm tra trang Astro này, thêm đa ngôn ngữ mà không đổi thiết kế và xác minh trên di động.”

</Example>

## Một quy trình đáng tin cậy

1. Mô tả kết quả và tiêu chí nghiệm thu
2. Kiểm tra tệp liên quan và quy ước hiện có
3. Thực hiện thay đổi và chạy kiểm tra phù hợp với rủi ro
4. Xem lại kết quả, khác biệt và bước tiếp theo

## Khi có sự cố

Giữ nguyên thông báo lỗi đầy đủ, kiểm tra thư mục làm việc và quyền, rồi thu nhỏ thành trường hợp tái hiện tối thiểu. Ưu tiên đầu ra thực tế thay vì phỏng đoán.

```bash
npm run check
npm run build
```
