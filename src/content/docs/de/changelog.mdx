## Mit Änderungsprotokoll beginnen

Beschreibe zuerst das gewünschte Ergebnis und liefere dann die nötigen Dateien, den Kontext und die Einschränkungen. Lass Codex das echte Projekt prüfen und jeden wichtigen Schritt verifizieren.

<Example>

„Prüfe diese Astro-Website, ergänze Mehrsprachigkeit ohne das Design zu ändern und teste sie mobil.“

</Example>

## Ein verlässlicher Ablauf

1. Ergebnis und Abnahmekriterien beschreiben
2. Relevante Dateien und bestehende Konventionen prüfen
3. Änderung umsetzen und risikogerechte Prüfungen ausführen
4. Ergebnis, Diff und nächsten Schritt prüfen

## Wenn etwas schiefgeht

Bewahre die vollständige Fehlermeldung auf, prüfe Arbeitsverzeichnis und Rechte und reduziere das Problem auf den kleinsten reproduzierbaren Fall. Nutze echte Ausgaben statt Vermutungen.

```bash
npm run check
npm run build
```
