## Начало работы: Разработчикам

Сначала сформулируйте ожидаемый результат, затем добавьте нужные файлы, контекст и ограничения. Позвольте Codex изучить реальный проект и проверять результат после каждого важного шага.

<Example>

«Проверь этот сайт Astro, добавь многоязычность без изменения дизайна и протестируй мобильную версию.»

</Example>

## Надёжный рабочий процесс

1. Опишите результат и критерии приёмки
2. Проверьте связанные файлы и правила проекта
3. Внесите изменения и выполните проверки по уровню риска
4. Просмотрите результат, изменения и следующий шаг

## Если что-то пошло не так

Сохраните полный текст ошибки, проверьте рабочую папку и права, затем сократите проблему до минимального сценария. Используйте фактический вывод вместо догадок.

```bash
npm run check
npm run build
```
