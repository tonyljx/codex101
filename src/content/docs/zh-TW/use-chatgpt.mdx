<Callout title="先從一個真實結果開始">

直接在任務中寫明你希望取得的檔案、頁面或驗證結果。

</Callout>

## 開始使用 使用 ChatGPT

先說明想完成的結果，再提供必要的檔案、背景與限制。讓 Codex 讀取真實專案，並在每個重要步驟後驗證結果。

<Example>

「檢查這個 Astro 網站，在保留現有視覺的前提下加入多語言，並以行動版驗收。」

</Example>

## 可靠的工作流程

1. 描述目標與驗收標準
2. 讓 Codex 檢查相關檔案與既有約定
3. 執行修改並進行與風險相符的檢查
4. 檢視結果、差異與下一步

## 發生問題時

保留完整錯誤訊息，確認執行目錄與權限，再縮小到最小可重現步驟。不要以猜測取代真實輸出。

```bash
npm run check
npm run build
```
