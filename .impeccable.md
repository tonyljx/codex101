## Design Context

### Users

Codex 101 serves developers, technical operators, security administrators, and new Codex users who need to learn workflows, find configuration details, and resolve implementation questions quickly. Most visits are task-oriented reading sessions across desktop and mobile, including long technical reference pages.

### Brand Personality

Calm, precise, and trustworthy. The interface should feel like a first-party technical product: restrained enough for sustained reading, polished enough to build confidence, and direct enough that decoration never competes with documentation.

### Aesthetic Direction

Match the information density, layout rhythm, typography, light/dark behavior, and interaction restraint of the Codex documentation references at `codex-docs.com` and `learn.chatgpt.com`. Preserve the existing neutral palette and editorial documentation layout. Avoid playful motion, bounce, glassmorphism, ornamental gradients, generic card-heavy redesigns, and effects that make navigation feel slower.

### Design Principles

1. Reading continuity comes first: navigation, search, anchors, and long-form content must remain fast and predictable.
2. Motion explains route and state changes; it uses short opacity/transform transitions and never animates layout dimensions.
3. Respect user preferences: light and dark themes, keyboard operation, responsive layouts, and `prefers-reduced-motion` are acceptance criteria.
4. Keep the static-first architecture: Astro renders content and React is limited to stateful interaction islands.
5. Maintain the 1:1 visual reference through shared components and tokens rather than page-specific styling.
